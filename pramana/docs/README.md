This is documentation for the `pramana/` Mix umbrella. Commands in these guides
run from that directory unless they explicitly name another working directory.
For an existing checkout, read [the layout transition](../../docs/LAYOUT_MIGRATION.md)
before corpus or model work. Source paths and local-data paths are not interchangeable.
