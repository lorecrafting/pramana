## Changes committed

### Guard F1 regression fix (new in CYCLE-01)

`check_output/1` in `Pramana.Guard` built a Map keyed by URN, keeping only the last associated quote. A fabricated quote followed by a genuine one with the same URN was silently dropped, and the guard reported `ok? true` — because it had found the last occurrence (correct) and never visited the fabricated one before it.

**Fix**: `citation_pairs/1` now tracks every URN occurrence independently by byte position, preserving duplicates and document order. Uses `Regex.scan(..., return: :index)` for position tracking with `return: :index`, then merges quoted citation positions with bare URN positions sorted by byte offset. Each occurrence carries `source_offset` (byte offset in the inspected text).
