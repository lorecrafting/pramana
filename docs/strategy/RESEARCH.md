## Adopt principles; evaluate implementations

The default is to build the minimal domain-specific evidence/authority contract and
reuse mature components where they fit. Do not build a memory SaaS or train a
translation model because an adjacent product exists. Do not reject all external
services as intrinsically unsafe; assess the actual data, authority, cost and
operating requirements. Foundry's standalone boundary remains a hard constraint.

| Candidate family | Gate before adoption | Not implied |
|---|---|---|
| `ex_ast`, `ex_dna`, `ex_slop`, `reach`, `exograph`, `vibe_kit` | Pin version; test compatibility and representative failures; measure review savings and false positives; inspect maintenance/licence | AST validity proves behavior, analysis sees every dynamic dependency, or all tools are already integrated |
| `phoenix_replay` or other UI capture | Reproduce the target failure; test external state and JS interactions; redact private inputs; compare with existing functional/browser tests | A small event log recreates every nondeterministic UI/environment state |
| Pi RPC | Exact pinned revision; strict protocol parsing; lifecycle/reconnect/cancellation/usage tests; admitted extension/tool inventory; FR-09/15a provider, billing and isolation conformance | Pi is already a Foundry authority boundary, a built-in sandbox, or production adoption is justified by its small size |
| `pi-elixir`, `vibe`, `llm_proxy` | Demonstrated missing capability and compliance with isolated execution and the selected harness/billing boundaries | Exposing arbitrary evaluation or a parallel provider route to the protected runtime |
| Mem0-like retrieval or graph ranking | Relevant held-out recall benefit, provenance and privacy/scope tests; deploy only in the appropriate independent system | Copying one SQL weighting formula reproduces a commercial memory service |
| MITRA-E, OCR and other upstream corpus artifacts | Actual artifact availability, terms, source fidelity, alignment, local retrieval evaluation and bounded spend | A research score or initiative announcement justifies a full production bake |
| Superlogical | I-F4's installed backend conformance and reversible cutover | A terminal pane proves workflow completion or session persistence proves execution isolation |
